# Сервис учёта материалов для творчества

Консольное приложение для учёта материалов для рукоделия
и художественных работ.

## Назначение

Приложение помогает людям, занимающимся творчеством, вести учёт материалов для рукоделия и художественных работ. Оно позволяет фиксировать, какие материалы есть в наличии, к какой категории они относятся и в каком количестве. Сервис решает проблему «забытых запасов»: пользователь всегда видит актуальный список своих материалов, может вовремя заметить, что что-то заканчивается, и не покупает лишнее.

## Целевая аудитория

- Художники и иллюстраторы (краски, кисти, холсты, бумага)
- Рукодельницы (ткани, нитки, пряжа, бисер, фурнитура)
- Студенты творческих специальностей
- Любители, у которых дома хранятся запасы материалов для хобби
- Небольшие творческие мастерские, ведущие учёт расходников

## Предметная область

Учёт материалов для творчества - это деятельность по ведению каталога расходников и инструментов, используемых в рукоделии и художественном творчестве. Каждый материал относится к определённой категории и характеризуется количеством на складе. Учёт позволяет контролировать остатки, планировать закупки и упорядочивать хранение.

## Основные сущности

- **Пользователь** — человек, который может добавлять, удалять и изменять материалы
- **Материал** — расходники и инструменты
- **Категория** — группа, к которой относится материал
- **Количество** — количество оставшегося материала

## Возможности (ПР2)

- просмотр всех материалов в виде таблицы;
- добавление материала с проверкой данных (при повторном добавлении
  того же материала увеличивается его количество);
- поиск материала по части названия;
- просмотр материалов выбранной категории;
- расход и пополнение материала;
- удаление материала;
- список материалов, которые заканчиваются (остаток ≤ 3);
- сортировка по названию, категории или количеству;
- статистика по учёту и по категориям;
- сохранение данных в JSON и загрузка при запуске.

## Формат данных

Материалы хранятся в файле `data/materials.json` списком словарей:

```json
[
    {
        "id": 1,
        "name": "Акварель Белые ночи",
        "category": "Краски",
        "count": 2,
        "added_at": "2026-09-20"
    }
]
```

В программе данные хранятся в словаре `materials`, где ключ — `id` материала.
